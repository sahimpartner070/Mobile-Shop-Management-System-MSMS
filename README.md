
# MSMS – Mobile Shop Management System

## Overview
MSMS – Mobile Shop Management System

MSMS is a C# .NET WinForms-based application developed for university submission to manage mobile shop operations such as products, customers, sales, and inventory.

MSMS (Mobile Shop Management System) is a simple and efficient application designed to help mobile shop owners manage their daily business operations digitally. The system provides an organized way to handle mobile products, sales records, customer information, and inventory management, reducing manual work and improving accuracy.

The project is suitable for small and medium mobile shops and is developed as a beginner-friendly system that demonstrates core concepts of software development, database handling, and business process automation.

## Technology Stack
- C# .NET (WinForms)
- SQL Server
- ADO.NET

## Features
- Product management
- Customer management
- Sales and billing
- Inventory tracking
- User authentication

## How to Run
1. Open the project in Visual Studio
2. Restore NuGet packages
3. Configure database connection
4. Run the application
